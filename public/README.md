# Heth OBS widget reference

The old URL-based account-key configuration and decorative QR skins are superseded by the restricted connection and scan-friendly overlay. See the [current implementation guide](../README.md) and [user documentation](https://docs.heth.me/user/obs).

Themes keep their existing identifiers for appearance selection. The payment QR remains high contrast with an unobstructed quiet zone. No secrets or account API keys belong in public assets. This update is not yet a production release.
