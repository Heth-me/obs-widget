# Heth OBS widget assets

This directory contains public logo assets for the Heth OBS browser source. Use themes to style the surrounding overlay while keeping the payment QR high contrast and its quiet zone clear.

- [Connect the widget in Heth](https://docs.heth.me/user/obs)
- [Build and customize the source](https://github.com/Heth-me/obs-widget)
- [Work on a layout with an AI assistant](https://github.com/Heth-me/obs-widget/blob/main/AI_GUIDE.md)

Keep account credentials and private OBS connection URLs out of public assets. Use the credential-free preview for visual work.
